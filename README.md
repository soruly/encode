# encode

[![](https://david-dm.org/soruly/encode/status.svg)](https://david-dm.org/soruly/encode)

A simple javascript all-in-one webpage for common encodings / hashings.

https://soruly.github.io/encode/

## Supported Encodings

- HTML
- Unicode
- URI
- URI Component
- Base64
- Base64URL

## Supported Hashings

- SHA1
- SHA256
- SHA384
- SHA512
